# Prompt para o Replit

Crie uma aplicação web focada em **um único funnel público** para gerar currículo por vaga com IA.

## Objetivo do produto

O produto **não é um SaaS com dashboard**.
O produto é um **fluxo direto**:

1. usuário entra direto no onboarding
2. responde 7 páginas
3. importa ou preenche o perfil base
4. cola a vaga
5. escolhe o modelo
6. o sistema gera uma prévia
7. o usuário vê valor
8. paga no Stripe
9. desbloqueia a versão final e baixa o PDF

Não criar:

* landing page
* dashboard
* sidebar
* billing interno de SaaS
* assinatura mensal
* área logada obrigatória

A home do app já deve abrir **direto na primeira página do onboarding**.

---

# Stack

Usar:

* **Next.js** ou **React + Vite**, mantendo a stack mais simples e estável no Replit
* **TypeScript**
* **Tailwind CSS**
* componentes limpos e modernos
* backend simples com rotas API
* persistência em banco relacional ou simples com JSON/ORM, priorizando velocidade
* **Stripe Checkout**
* geração de PDF final
* parser de currículo
* integração com IA para:

  * estruturar perfil base
  * analisar vaga
  * calcular score ATS estimado
  * gerar versão otimizada do currículo

## Prioridade de arquitetura

A prioridade é:

* fluxo rápido
* UX limpa
* persistência da sessão
* geração confiável
* pagamento funcional

# Estrutura principal do produto

Criar **um funnel público** com uma sessão anônima persistida por `sessionId`.

## Sessão pública

Ao entrar no fluxo, criar uma sessão pública com um `sessionId` e salvar em localStorage/cookie.

Essa sessão deve guardar:

* respostas das páginas 1 a 7
* dados do perfil base
* dados da vaga
* modelo escolhido
* preview gerado
* score ATS
* status do pagamento
* PDF final liberado ou não

# Stripe

## O que implementar

Usar **Stripe Checkout**.

### Lógica

Ao clicar em “Desbloquear por R$ 19,90”:

1. criar `checkout session`
2. enviar `publicSessionId` no metadata
3. redirecionar para o Stripe
4. após pagamento, webhook confirma
5. liberar o currículo final

## Não criar

* assinatura
* planos mensais
* créditos
* billing de usuário
* carteira de saldo

## Tela de sucesso

Depois do pagamento:

* mostrar confirmação
* voltar para a tela final da sessão
* liberar preview completo e PDF
